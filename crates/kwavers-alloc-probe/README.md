# kwavers-alloc-probe

Thread-scoped allocation counting for kwavers allocation-contract tests.

`kwavers-alloc-probe` is a member of the [kwavers](https://github.com/ryancinsight/kwavers) workspace, an interdisciplinary ultrasound-light physics simulation library. It sits in the foundation layer (no first-party dependencies). The workspace is split into per-layer crates with strictly unidirectional dependencies and no facade: depend on the crates you need directly.

## Usage

```toml
[dependencies]
kwavers-alloc-probe = "0.1.0"
```
