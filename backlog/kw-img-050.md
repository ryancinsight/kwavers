## KW-IMG-050 — Absolute-magnitude gap in the corrected Kuji metric (simulated reductions ≈ 2.4–2.7 vs the paper's large experimental reductions) [minor] — blocked

priority: feature; needs: none; basis: eb91da65678bcd26cba72e67ae42b1b80e732132; scope: triplet-pulse imaging model (medium, cloud, noise floor); milestone: M-imaging-capability

- **Outcome:** the corrected Kuji metric (KW-IMG-047) applied to simulated RF produces tissue/cavitation reductions of the same order as the experiment, so that contrast *shape* claims (including the 0.26 MPa peak question) can be adjudicated on a quantity whose absolute scale is physical.
- **Driver:** Build 14 B1 ran the corrected metric as an ensemble (n = 5, coherent DAS, declared probe band): the simulated contrast is ≈ 0 dB at every PNP and cutoff because both reductions sit at ≈ 2.4–2.7 linear, while Kuji's experimental reductions are large (contrast at the ~10–40 dB scale). B3's coupled runs, under the prototype's numerical floor, showed the complementary failure (reductions in the thousands, floor-set). Either way the absolute magnitude is not the paper's, and the 0.26 MPa peak question is downstream of this gap: a few-dB peak cannot be confirmed or refuted on a floor-dominated or magnitude-mismatched quantity.
- **Named contributors (audit §d #13 and B1/B3 findings):** (1) tissue nonlinear-leak path 3–6× shorter in the prototype geometry (≈ 20 mm vs Kuji's 70 mm to focus), so the HP-band tissue leak that sets the tissue reduction accumulates far less; (2) full-N cloud scattering — the physical cloud is ~10³ bubbles per focus over six foci surrounding the ROI, the prototype images one small cloud *in* the ROI; (3) a physical noise floor — the experiment's floor is system noise; the simulation's is a declared added-noise model whose level moves the low-cutoff contrast by ~10 dB (B1 sensitivity), so any headline number needs a floor-sensitivity run beside it.
- **Acceptance:** a simulated configuration whose corrected-metric reductions and contrast land on the paper's scale for a stated reason (measured against Kuji Figs. 12–14 magnitudes), with the floor model and its sensitivity declared; only then re-run the step-10 peak test as an adjudication of the experiment rather than of the model.

- **Current state (Build 17, 2026-11-23, `B17_RESULTS.md`):** the floor is a declared SNR-parameterised model (`DeclaredNoiseFloor`, default none). Floor-free residuals: the tissue slope is wrong in both geometries (B1 slope −28.8 dB vs the paper's −6.5 dB; the long plane-wave path collapses with the Gol'dberg number Γ); cavitation over-cancels in the short geometry (86 lin vs the paper's 8.4 @0.26 MPa) and sits within +1.0 dB of target in the long one; coupled driving (KW-PHYS-013) explains ≈ 8 % of the gap. The K1 failure is attributed to the tissue model's uncalibrated absolute backscatter level (smooth 1.3 < paper 31.4 < discrete 39.1 dB, floored, 0.26 MPa bin; KW-IMG-056); absorption is excluded at both literature endpoints in the smooth medium. Status stays open.
- **Next step:** calibrate the tissue backscatter level (KW-IMG-056) and re-score against KW-IMG-052; remaining levers: across-fibre absorption bracket (alpha0 = 2.57), discrete-scatterer tissue at the long geometry, a focal-volume PNP estimator, ensemble seeds for near-target configurations (Build 15 geometry numbers are seed 21 only).
- **Blocker:** the acceptance cannot run from tracked files: it re-runs the replica pipeline (tissue model, cloud, noise-floor harness), which exists only as the untracked `b16/` harness scored in the untracked `B15_RESULTS.md` to `B17_RESULTS.md`; the tracked metric and `DeclaredNoiseFloor` are only its scoring half, and a tracked discrete-scatterer RF synthesis (`crates/kwavers-phantom/src/scatterers/`) and bubble-cloud orchestrator (`crates/kwavers-simulation/src/imaging/triplet_pulse.rs`) exist but are parts, not that pipeline.
- **Re-open trigger:** the replica harness `b16/` and the result files `B15_RESULTS.md` to `B17_RESULTS.md` becoming tracked in this repository, or a respecification item for the replica programme landing on the board.
