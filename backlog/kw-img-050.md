## KW-IMG-050 — Absolute-magnitude gap in the corrected Kuji metric (simulated reductions ≈ 2.4–2.7 vs the paper's large experimental reductions) [minor] — todo

priority: research; needs: none; scope: triplet-pulse imaging model (medium, cloud, noise floor); milestone: M-imaging-capability

- **Outcome:** the corrected Kuji metric (KW-IMG-047) applied to simulated RF produces tissue/cavitation reductions of the same order as the experiment, so that contrast *shape* claims (including the 0.26 MPa peak question) can be adjudicated on a quantity whose absolute scale is physical.
- **Driver:** Build 14 B1 ran the corrected metric as an ensemble (n = 5, coherent DAS, declared probe band): the simulated contrast is ≈ 0 dB at every PNP and cutoff because both reductions sit at ≈ 2.4–2.7 linear, while Kuji's experimental reductions are large (contrast at the ~10–40 dB scale). B3's coupled runs, under the prototype's numerical floor, showed the complementary failure (reductions in the thousands, floor-set). Either way the absolute magnitude is not the paper's, and the 0.26 MPa peak question is downstream of this gap: a few-dB peak cannot be confirmed or refuted on a floor-dominated or magnitude-mismatched quantity.
- **Named contributors (audit §d #13 and B1/B3 findings):** (1) tissue nonlinear-leak path 3–6× shorter in the prototype geometry (≈ 20 mm vs Kuji's 70 mm to focus), so the HP-band tissue leak that sets the tissue reduction accumulates far less; (2) full-N cloud scattering — the physical cloud is ~10³ bubbles per focus over six foci surrounding the ROI, the prototype images one small cloud *in* the ROI; (3) a physical noise floor — the experiment's floor is system noise; the simulation's is a declared added-noise model whose level moves the low-cutoff contrast by ~10 dB (B1 sensitivity), so any headline number needs a floor-sensitivity run beside it.
- **Acceptance:** a simulated configuration whose corrected-metric reductions and contrast land on the paper's scale for a stated reason (measured against Kuji Figs. 12–14 magnitudes), with the floor model and its sensitivity declared; only then re-run the step-10 peak test as an adjudication of the experiment rather than of the model.

### Build 15 decomposition (Nov 22, 2026) — status stays open

Build 15 (`B15_RESULTS.md`, WS-A/WS-B/WS-C) decomposed the gap against the representation benchmark (now KW-IMG-052). The headline gap is **100 % floor at low PNP**: with nonlinearity OFF, B1's geometry returns the same tissue reduction (2.60 lin @0.26 MPa) as B1's nonlinear headline — at σ = 1e-3 the tissue side never measured physical leak (WS-C: imposed DAS-level in-band SNR ≈ −23 dB; reductions pinned to the statistic's pure-noise asymptote ≈ 2.40; WS-A linear control agrees). The floor is now a declared, SNR-parameterised library model (KW-IMG-047 module, `DeclaredNoiseFloor`); the default remains no added noise.

Floor-free residuals (σ = 0), which are the real remaining gap:

- **Tissue slope wrong in both geometries.** B1 (short) geometry: overshoot at low PNP (+16.8 dB @0.12, +8.9 @0.26 MPa, fc 3.0), −0.1 dB @0.72, −5.5 dB @1.23; slope −28.8 dB vs the paper's −6.5 dB. Long plane-wave geometry (53 mm path): the reduction collapses via the Gol'dberg number Γ (∫βp dz at fixed ROI PNP) — down 39 dB @0.26 and 19 dB @1.23 MPa, top-PNP shortfall −25.0 dB; no PNP within ±3 dB. Γ orders diverging (9.0× B1) > plane (6.6×) > focused sector (4.5×) > B1 (1×), with a threshold-like response (Γ = 0.04 → 40 dB; Γ = 0.27 → 1.3 dB).
- **Cavitation over-cancellation is geometry-dependent.** Floor-free in B1 geometry the bubbles over-cancel (86 lin vs the paper's 8.4 @0.26 MPa, fc 3.0 — WS-C). In the long geometry the centred cloud is already within +1.0 dB of the cavitation target @0.26 MPa (only there; six-foci placement moves it +3.1 dB away, ~0 @1.23).
- **Coupled driving (WS-B, now KW-PHYS-013):** +0.83 dB of cavitation reduction @0.26 MPa / fc 3.0 — ≈ 8 % of the gap, sign-reversing at 1.27 MPa; excluded as the explanation.

Remaining levers, in order: (1) **frequency-dependent attenuation** — absent from every configuration run so far, and in real chicken breast it caps exactly the cumulative distortion Γ measures; (2) **focused sector profile** — the only long-path profile not yet simulated to completion (runs in flight at filing time; Γ ≈ 4.5× B1, interpolated tissue reduction between the two simulated Γ points); (3) **ensemble seeds** for the near-target configurations (all Build 15 geometry numbers are seed 21, single realisation).

- **Acceptance (unchanged):** the Build 15 representation benchmark (KW-IMG-052) — a configuration passes when its corrected-metric reductions and contrast land on the paper's scale for a stated reason, with the floor model and its sensitivity declared.
