## KW-IMG-047 — Corrected Kuji 2024 3P/1P-distribution metric (coherent DAS, linear reduction, ensemble) [minor] — done (Nov 21, 2026)

priority: feature; needs: none; scope: `kwavers-analysis` signal processing (`signal_processing/triplet_pulse_metrics.rs`); milestone: M-imaging-capability

- **Outcome:** Kuji 2024's own contrast quantity — per-pixel linear 1P/3P reduction of high-pass-filtered, coherently beamformed RF, averaged over a declared ROI in before/after frames, contrast `20·log10(tissue/cavitation)`, with an ensemble path averaging reductions over ≥ 5 realisations — is a reusable library component, superseding the KW-IMG-046 proxy contrast for any Kuji claim.
- **Driver:** the Build 14 Stage A audit (`B14_AUDIT.md` §e) found the previously implemented statistic was not Kuji's: the headline was mean-of-dB (the paper averages the linear reduction), the beamformer took the envelope before the aperture sum (the paper beamforms RF coherently to IQ), an artificial ratio floor `1e-6 × global 1P max` stood in for a physical noise floor, and the evaluation was a single realisation where the paper averages five. The audit reclassified the earlier "peak does not survive Kuji's own metric" verdict as INCONCLUSIVE.
- **Acceptance:** spec steps 1–10 of `B14_AUDIT.md` §e implemented as declared: Kuji-shaped high-pass (passband = attenuation-start, −60 dB stopband, 0.15·fc transition; brick-wall as declared sensitivity), fc sweep restricted to 2.3–3.7 MHz in 0.1 MHz steps, no low-pass (optional declared probe band 1.5–4.3 MHz), coherent DAS with envelope after the aperture sum, linear per-pixel ratio with no artificial floor, before/after ROI reductions, ensemble averaging of reductions before the contrast (Fig. 12 method) with per-realisation mean ± SD reported, and an optimal-cutoff trajectory helper for the step-10 peak test. Unit tests on synthetic signals with analytically known reductions.

### Resolution (Nov 21, 2026)

- **Implementation.** `crates/kwavers-analysis/src/signal_processing/triplet_pulse_metrics.rs`: `kuji_hp_response` / `kuji_filter_trace` (zero-phase, half-spectrum FFT — the full apollo FFT's packed split layout is not the DFT bin layout), `coherent_das_envelope`, `kuji_images` (combine → filter per channel → coherent DAS), `roi_mean_reduction`, `kuji_contrast_from_images`, `kuji_ensemble`, `optimal_cutoff`, `RectRoi` (paper ROI 62–68 mm × ±3 mm), constants `KUJI_FC_GRID_HZ`, `KUJI_PROBE_BAND_HZ`, `KUJI_PNP_PA`. The same module implements the corrected Iwasaki statistic (spatiotemporal max ÷ same-frame background mean over 70–100 mm × ±16 mm; linear vs dB-brightness background averaging both provided, choice declared — see KW-IMG-049). The KW-IMG-046 proxy module now carries a supersession note pointing here; its DAS/retention parity tests are unchanged and still pass.
- **Reference check.** The Python reference implementation of the same spec (`kwavers-work/b14/metric.py`) reproduces the audit's seed-11 legacy numbers to ≤ 0.02 dB; this Rust component is unit-verified on analytic signals (filter stopband/passband, DAS impulse localisation, known-ratio images → known contrast, ensemble arithmetic).
- **Result carried (B14 B1).** With the corrected metric the simulated contrast is ≈ 0 dB at every PNP and cutoff (reductions ≈ 2.4–2.7 linear on both sides): Kuji's 0.26 MPa peak is absent as an ensemble property of the corrected metric in this model, and the falling-optimal-cutoff behaviour is not reproduced. The absolute-magnitude gap to the paper's scale is a separate open item (KW-IMG-050), not a metric error.
