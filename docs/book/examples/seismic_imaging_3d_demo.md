# Example: Seismic Imaging 3D Demo

**Crate**: `kwavers`
**Run**: `cargo run -p kwavers --example seismic_imaging_3d_demo`
**Source**: [`crates/kwavers/examples/seismic_imaging_3d_demo.rs`](../../../crates/kwavers/examples/seismic_imaging_3d_demo.rs)

## What This Example Demonstrates

True 3D transcranial ultrasound FWI — extends the 2D quasi-3D demo to full 3D
(NX=64, NY=48, NZ=64) with Fibonacci-sphere acquisition geometry, trilinear
CT resampling, and optional co-registered T1 MRI mapping selected explicitly.

Set `KWAVERS_SEISMIC_INPUT_MODE=synthetic` for the deterministic analytical
phantom, `ct:<ct-path>` for CT-only input, or
`ct-mri:<ct-path>|<mri-path>` for co-registered CT and T1 MRI. A selected file
that cannot be loaded is a typed run error; the workflow does not skip the
stage or substitute another prior. Outputs default below
`target/seismic_imaging_3d_demo/`; an empty brain acquisition or failed RTM
stage is also returned as a typed error.

Source pressure is generated by the same `DomainRickerWavelet` used by the
2-D workflow and reverse-time migration. Frequency, peak pressure, and sample
time enter that provider as Aequitas quantities, and its iterator writes
directly into the solver source array.

The CT and synthetic HU volumes share the same
`seismic_imaging::medium::SkullModel`. It delegates density, sound speed, and
1 MHz attenuation to `HeterogeneousSkull::from_ct_hill` with Aequitas-typed
canonical cortical-bone properties; the example contains no HU-to-property
formula.
